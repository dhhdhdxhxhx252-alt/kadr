# Kadr — запись экрана для Android

Небольшое приложение, которое пишет экран в MP4: без аккаунтов, без рекламы, без
облака. Всё остаётся в `Movies/Kadr` на телефоне.

Код написан с нуля на Kotlin: ни одна строка и ни один ресурс не перенесены из
сторонних рекордеров.

## Что умеет

- Запись экрана через `MediaProjection` + `MediaCodec` (поверхность кодека) + `MediaMuxer`, H.264/AAC.
- Foreground-сервис: запись не рвётся, когда приложение свёрнуто; в уведомлении —
  хронометр и кнопка «Остановить».
- Качество (короткая сторона 540/720/1080/1440), частота кадров 15/30/60,
  звук «без звука» или «микрофон», ограничение длительности 5/15/30/60 минут или без лимита.
- Отсчёт 3–2–1 перед стартом, чтобы успеть открыть нужное приложение.
- Список записей прямо в приложении: размер, длительность, «поделиться» и «удалить».
- Если система отзывает разрешение на показ экрана, запись останавливается, а
  недописанный файл удаляется, чтобы не засорять галерею.

## Сборка

Нужен JDK 17+ и Android SDK с platform 34 и build-tools 34.

```bash
./gradlew assembleDebug          # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease        # minify + shrinkResources, подпись своей подписью
```

Установка на устройство:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Как устроено

| Файл | Зачем |
| --- | --- |
| `Options.kt` | Пресеты качества/частоты/звука/лимита и их хранение в `SharedPreferences`. |
| `EncoderLimits.kt` | Границы энкодера конкретного устройства: размер кадра и битрейт режутся по `MediaCodecList`, чтобы `configure()` не падал. |
| `Library.kt` | `MediaStore`: создание файла в `Movies/Kadr`, список, удаление. На Android 8–9 — прямой путь и `WRITE_EXTERNAL_STORAGE`. |
| `RecordingSession.kt` | Сама труба: `VirtualDisplay` → surface видеокодека, отдельный поток на микрофон, один `MediaMuxer` под замком. |
| `RecorderService.kt` | Foreground-сервис, уведомление, отзыв разрешения системой. |
| `MainActivity.kt` | Чипы настроек, кнопка записи, отсчёт, список записей. |

Два потока пишут в один `MediaMuxer`: дорожки добавляются по `INFO_OUTPUT_FORMAT_CHANGED`,
`start()` вызывается только когда готовы обе, а остановка ждёт EOS с видео и с аудио.
Буферы, которые кодек отдаёт меньше заявленного `BufferInfo.size`, копируются в прямой буфер.

## Разрешения

| Разрешение | Когда нужно |
| --- | --- |
| `RECORD_AUDIO` | только если выбран звук с микрофона |
| `POST_NOTIFICATIONS` | Android 13+, чтобы показать уведомление о записи |
| `WRITE_EXTERNAL_STORAGE` | только Android 8–9 (на 10+ не запрашивается) |
| `FOREGROUND_SERVICE_MEDIA_PROJECTION` | Android 14 требует foreground-сервис типа mediaProjection |

Разрешение на показ экрана (`MediaProjection`) запрашивается на каждый запуск записи —
так работает система, обойти это нельзя.

## Известные ограничения

- Пишется портретная рамка: если во время записи повернуть приложение в ландшафт,
  кадр останется вертикальным.
- Внутренний (системный) звук не пишется — Android разрешает его только с Android 10
  и только отдельным типом захвата; здесь есть только микрофон.
- Сборка проверена компилятором, но не обкатана на реальном устройстве.
